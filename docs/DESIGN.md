# MIN-1 设计

MIN-1 是 M-VAVE FM-1 上的一个极简主义"过程音乐"固件，风格参照 Philip Glass 的 *Glassworks*（1982）。
开机就自己演奏：几条琶音层层交错（三连音对八分音符，2:3），和弦在短循环里反复，乐句按"加法过程"一点点变长再变短，
各声部一段一段地进出。你可以按住琴键给它新的和弦，它马上用你的和弦继续织下去；也可以用 REC 教它一整段和弦循环。

工作名 MIN-1，随时可以改。产品名和预设名都不用真人名字或作品名（*Glassworks* 只是风格参照）。

## 来源

从 AMB-1（charlesvestal/fm1-amb，d4a211c）的代码树开始，平台层来自 Felucca（经 X0X、FoMni、AMB-1），GPL-3.0-only。
保留：`hal/`、`loader/`、`usb.c`、`storage.c`、`ota.c`、`main_fm1.c`、`panel.c`、`plat*`、`fastmath.h`、主机模拟器、浏览器模拟器、安装工具。
重写：`firmware/src/dsp/`（乐器）、`firmware/src/app/ui.c`（界面）、`project.c`（存档）、测试和场景脚本。
Dattorro 板式混响照搬 AMB-1 的实现。

## 身份

- 包身份 `FM-1_5XXYYZZ`（发布版），开发版 `FM-1_500`。hub 上 `FM-1_5` 开头没人用。
- USB 名称："MIN-1" / "MIN-1 FM-1"。输出 `build/min.fwsc`。
- 引擎 `dsp/min.c` / `min.h`，接口前缀沿用 `en_`（engine），平台胶水代码基本不用动。

## 时间

- 24 PPQN（和 MIDI 时钟一致）。速度 40–200 BPM。
- 每个声部有自己的"脉冲"：每拍 2、3、4 或 6 个音（每 12、8、6、4 个 tick 一步），所以 3 对 2、4 对 3 自然出现。
- 采样级精确：渲染循环在 tick 边界切块（同 AMB-1）。

## 和声：循环

- 和弦循环库（ALGORITHM 旋钮选择），每个循环 2–8 个和弦，每个和弦 = 相对主音的半音数 + 性质 + 低音（可以是转位）。
  都是通用的套路，不抄任何具体作品：
  - 小调：i–VI–iv–V、i–VI–III–VII、i–iv–VI–V、i–VII–VI–V、i–VI、i–i/♭7–VI–V（下行低音）、i–III–VI–iv–V、i–VI–♭II–V
  - 大调：I–vi–IV–V、I–IV–I–V、I–iii–vi–IV、I–V/3–vi–IV、IV–V–iii–vi、I–II（利底亚）、I–♭VII–IV–I、I–♭VI–♭VII–I
  - 加上一格"Mine"：你用 REC 教的循环。
- Root（主音，Setup 页）整体移调。
- Chord（Form 页）：每个和弦几拍：2、4、8、16。

## 按键接管

- 按住 2 个以上的键：和弦就是你按的这些音，最低的那个当低音。
- 只按 1 个键：用这个音当根音，按当前循环的大小调色彩配一个顺阶三和弦（小调：i、ii°、III、iv、V、VI、VII；大调：I、ii、iii、IV、V、vi、vii°；调外音配大三和弦）。
- 各声部下一步就换成新和弦。松开后，你的和弦一直保持到循环的下一个和弦边界；循环的位置在后台一直走，所以曲式不乱。
- MIDI 输入的音符（任何通道）等同按键。

## REC：教它一个循环

按 REC 进入学习：每按一次和弦再全部松开，就记下一个和弦（这次按过的所有键）。最多 8 个。再按 REC（或记满 8 个）结束，
这个循环存进当前曲目的"Mine"格，ALGORITHM 会停在 Mine。少于 2 个和弦就取消。学习时你的和弦照样发声。

## 曲式

- 段落 = 循环重复若干次。Evolve 低时一段重复 4–8 次，高时 1–2 次。
- Build：几分钟一个周期的"弧线"，在稀疏和饱满之间起落。每到段落边界，一次进或出一个声部，朝弧线的目标走
  （*Glassworks* 常见的一层一层叠上去，再一层一层撤下来）。Build 为 0 时所有声部一直在。
- Process：加法过程。段落开始时，琶音声部有一定概率进入"加法/减法"：乐句从 2 个音开始，每重复几遍加 1 个音，到最长再减回来。
  乐句长度一变，重音就在拍子上移动。Process 为 0 时乐句固定不变。
- Evolve：变化的快慢——段落长度、换乐句型、偶尔替换循环里的一个和弦。
- EDIT：下一个和弦边界就进入新段落。
- 力度分台阶：每个段落一个力度层次（p、mp、mf），段内不渐变；和弦层的"Swell"节奏例外（每个和弦一次渐强）。

## 五个声部

| 声部 | 页面 | 内容 | 音色 |
|---|---|---|---|
| Upper | ENV | 高音区琶音（右手） | 钢琴、风琴、长笛、弦乐、马林巴 |
| Lower | ARP | 中低音区琶音（左手） | 钢琴、风琴、弦乐、马林巴 |
| Bass | LFO | 低音：长音、八分脉冲、八度跳、根五 | 合成贝斯、风琴、弦乐、钢琴 |
| Lead | SEQ | 长线条旋律，每个循环重复，偶尔变化；可以加一个三度/六度的第二声部 | 萨克斯、长笛、圆号 |
| Chords | FX | 持续和弦（声部进行）、渐强、八分脉冲和弦 | 弦乐、风琴、圆号 |

琶音的乐句型（Figure）：把和弦音在声部音区里从低到高排成一列，乐句就是这列里的位置序列，超出就升八度：
上行、下行、上下行、分解（1-5-3-8）、阿尔贝蒂（1-5-3-5）、摇摆（两个音来回）、波浪、跨越。每个乐句重复的第一个音有重音，
这样加法过程能听出来。

## 音色合成（只用单精度浮点、无 libm）

- 钢琴：模态合成。每个音 6 个分音（带琴弦的非谐性），前两个分音各用两个阻尼谐振器（快衰减 + 慢衰减，略微失谐，产生拍频和双段衰减），
  加一个很短的击弦噪声。力度控制亮度。踏板：换和弦时，不在新和弦里的音约 150 ms 内制音。
- 马林巴：同一套模态引擎，3 个分音（1 : 3.9 : 9.2），衰减快，加琴槌噪声。
- 风琴：简易电风琴（8' 的 polyBLEP 方波加 4' 的正弦，再过低通），开关式包络，轻微颤音。4' 用正弦而不是第二个方波，是为了省 CPU。
- 长笛、弦乐、萨克斯、圆号、合成贝斯：同一个减法合成声部（两个振荡器 + 噪声 + SVF 滤波 + 共振峰 + ADSR + 颤音），各用一套参数表。
- 空间：AMB-1 的 Dattorro 板式混响，Room 控制送量和长度。不加磁带回声（Glass 的声音偏干）。
- 总线：tanh 软削波，再乘 MASTER 旋钮。

## 预设（8 首曲目，名字自己起）

Morning（钢琴独奏，3 对 2）、Glacier（风琴、圆号、弦乐，快，明亮）、Lagoon（长笛和弦乐，舒缓）、Machine（风琴和萨克斯，快速驱动）、
Skyline（萨克斯旋律在弦乐琶音上）、Evening（钢琴 + 弦乐 + 圆号）、Counting（风琴，严格的加法过程）、Prism（马林巴和钢琴交错）。
每首记住你改过的设置；按住 SAVE 恢复配方。

## 屏幕

- 顶栏：曲目标签、主音和循环名、速度和节拍灯、未保存的小点。
- 中间：上面一排是循环里的和弦格（当前格高亮，下面一条进度线，右上角是第几遍）；接管时显示"YOURS"和你的和弦，学习时显示"LEARN 3/8"。
  下面五条声部轨：名字、脉冲数、乐句的点（亮的是当前长度，最亮的是正在弹的那个音），不在当前段落里的声部变暗。
- 底栏：四个旋钮（沿用 X0X / AMB-1 的样式）。
- 配色：冷色的"玻璃"色系，浅灰蓝底、深蓝墨色，每个声部一个颜色。

## MIDI

- 输出：Upper 1 通道、Lower 2、Bass 3、Lead 4、Chords 5，外加时钟和开始/停止（Setup 里可关）。
- 输入：音符 = 按键；时钟驱动速度。

## 存档

一个 flash 对象：magic "MIN1"、格式 1、当前参数、灯光、当前曲目，以及 8 首曲目各自的参数和"Mine"循环（最多 8 个和弦，每个是 12 位音级掩码 + 低音）。

## 预算

- CPU：Mac 的耗时不能代表 FM-1 这种顺序执行的核心，所以改数"每帧执行的指令数"（标量编译）。用 X0X 手册公布的
  PERF TEST 真机负载（43%、83%、115%）标定：每帧 1 条指令约等于 FM-1 单核的 0.030%。按这个尺度，AMB-1 的曲目是
  36–44%（最忙一块 42–54%），MIN-1 是 34–57%（最忙一块 43–79%）。`tests/host/min_render.c` 每次都会打印这个估计。
- 过载保护（仿 X0X）：平台每渲染完一块就报告负载。超过 90%（或平均超过 82%）时，减法合成声部去掉第二个振荡器，
  每个琶音声部只留 2 个复音，钢琴的分音在 −60 dB 就结束；连续 3 秒低于 65% 后恢复。Setup 页 CPU 旁边会显示 G。
  上机后在 Setup 页看真实的 CPU 百分比。
- 内存：去掉磁带回声后，池里多出约 124 KB；混响约 139 KB。构建检查保持 ≥ 8 KiB 余量。

## 测试

- 主机单元测试：循环表算出的和弦、转位低音、单键/多键接管、REC 学习、乐句和加法过程的长度序列、2:3 的起音时间在 10 分钟里不漂移、
  每个声部单独开时有声音、关掉时无声、10 分钟无 NaN 且不削波、固定种子可复现。
- 场景脚本：开机、翻页截图、按键接管再松开、REC 教循环、切曲目、保存后重启。
- 每首曲目渲染一段 WAV 给你听，按你的耳朵再调。
- 最后 `./build.sh` 出固件；刷机前先问你。

# 0.2：从"听"到"做"

0.1 更像一台自己演奏的机器。0.2 的目标：先从自动演奏里听到灵感，再把自己的想法放进去，最后录成一首歌。不需要懂乐理。

## 四种模式（System 页的 Model，也随曲目切换）

| 模式 | 手法 | 实现 |
|---|---|---|
| ARPEGGIO | 和弦音琶音循环，2 对 3，加法过程 | 0.1 的方式 |
| PHASE | 两个声部弹同一句；下声部慢慢领先（Process = Drift 漂移速度），领先整一步后锁住一段（Evolve 越高锁得越短），再漂移，最后回到齐奏 | 下声部的音按领先的小数部分提前发声（声部可以"等"若干采样再起音），所以漂移是连续的；SHIFT 手法把它直接推前一步 |
| PATTERNS | 16 个短乐句组成一串，每句都是上一句的小改动（多一个音、少一个音、移一步、变长短、加一个呼吸）；上声部、下声部、旋律三个"演奏者"各自重复自己的乐句，想走就往下走，但不能比最慢的那个领先超过 Spread；全部走到最后一句，就一起从头再来。上方配一个高音脉冲（Chords 的 Pulse 节奏） | 乐句由 Line 种子生成；音高是相对当前和弦根音的音阶级数 |
| BELLS | 旋律从主音出发按音阶级进，一句比一句长一个音（最长到 Phrases），上下交替，句间换气；每个旋律音，上声部的"钟"都用和弦的三和弦里最近的音回应（在上方、下方、轮流、上方第二个）；下声部照常慢慢转动和弦 | 旋律由 Line 种子生成 |

## 20 首预设

ARPEGGIO 8 首（0.1 的），PHASE：Drift、Breath、Weave、Tilt；PATTERNS：Bazaar、Field、Gears、Murmur；BELLS：Vigil、Snowfall、Lantern、Chapel。另外加了两个单和弦的"静止"循环：Still（小调 i7）和 Glow（大调 Iadd9）。每个循环都有一个不用懂乐理的名字（Cadence、Epic、Lament ……）。

## 不用乐理的琴键（Setup：Keys、Hold）

- EASY（默认）：白键从左到右是这个调的七个和弦，最左边是主和弦，往右一个八度后重复；黑键是它左边那个白键的和弦再加七音。按几个键，就是它们的和弦合在一起，最低的那个当低音。不管按哪里都和谐。
- NOTES：按真实音高，跟 0.1 一样。
- HOLD：松手后和弦保留，直到再按一次同一组键。
- 琴键灯显示当前和弦落在哪些键上，可以跟着弹。

## 点子（EDIT）和撤销（SEL + EDIT）

点子就是"种子"参数：Form 页掷一个新和弦循环（Rolled），Upper/Lower 页掷一个新乐句型（Rolled，长度 3 到 12），Lead 页掷新旋律线、新 BELLS 旋律或新 PATTERNS 乐句串，Bass 页换一种低音走法，Chords 页换一种节奏。PHASE 模式下，Upper 页的点子同时给两个声部同一句，让它们彼此错位。因为点子就是参数值，所以它和别的参数一样会被保存、被录进歌里，撤销就是把值改回去（最多 12 步）。

## SEL：亲手

按住 SEL 时，屏幕显示这一层的说明：ENV、ARP、LFO、SEQ、FX 让对应声部在下一个和弦处进场或退场（Build 自动归 0，编排交给你）；EDIT 撤销点子；REC 学一个和弦循环；PLAY 切换歌曲/现场；白键 1–8 依次是 GROW、SHRINK、SHIFT、FLIP、STILL、慢一倍、快一倍、新段落，作用在当前页的琶音声部上（不在琶音页时两个都作用），在下一遍乐句开头生效。

## 录歌（REC）

- REC：从头开始，录下之后的所有操作（和弦、旋钮、点子、声部进出、手法），以及当时的全部参数和"骰子"。再按 REC 结束，歌就留在当前歌曲槽里，并进入 SONGS 模式。
- PLAY：从头回放，逐拍、逐音和录的时候一样（测试验证过：回放的每个音都在同一拍点、同一音高上）。
- SEL + PLAY 切换 SONGS/LIVE；SONGS 模式下 PRESETS 选歌曲槽（共 8 个），按住 SAVE 删除这首歌。
- 一首歌最多约 1880 个操作（同一个旋钮半拍内的转动只记最后一个值），存在 0x97000 开始的 4 个闪存对象里。

可重放的前提：音乐上的随机决定只在节拍上和命令执行时发生（噪声和振荡器相位用另一套随机数）；录制和回放都先回到同一个"音乐起点状态"，再按记录的拍点执行命令。
